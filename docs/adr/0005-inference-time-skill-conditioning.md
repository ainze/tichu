# ADR-0005: Inference-time skill conditioning uses the Neutral Decile

- **Status:** Accepted — **partially superseded by [ADR-0024](0024-master-tier-conditions-on-top-skill-decile.md)** for the `master` tier (a measured +10.6 pts/round favoured Decile 9). Still in force for `easy`/`medium`/`hard`.
- **Date:** 2026-05-25
- **Related:** [ADR-0001](0001-trunk-architecture.md), [ADR-0024](0024-master-tier-conditions-on-top-skill-decile.md)

## Context

The Policy Network is conditioned on a **Skill Decile** input ([ADR-0001](0001-trunk-architecture.md)'s
shared Trunk + per-Head architecture). During training, each example carries
the BSW player's Skill Decile in `0..9`, plus a sentinel **Neutral Skill
Decile** (`10`) for examples whose handle did not survive the Min-games
Filter.

At inference time, the requesting game server does not know — and is not
asked for — the human player's skill. The ML Agent must choose what value
to feed into the Skill Embedding for the current Decision. The candidates:

1. **Neutral Skill Decile** (`10`). The bucket trained on cold-start /
   ineligible players, plus whatever else falls outside Min-games.
2. **Decile 9** (top tier). The bucket trained on the strongest BSW
   players — superficially "best policy".
3. **Difficulty-dependent decile** (e.g. `medium=4, hard=7, master=9`).
   Reuse the Difficulty knob to vary skill conditioning.

## Decision

**Feed the Neutral Skill Decile (`10`) at inference, regardless of
Difficulty.** Encoded as `_NEUTRAL_SKILL = 10` at
`tichu_inference/ml_agent.py:45`, fed at line 121.

Difficulty differentiates by Checkpoint choice (`medium/hard/master` =
different BC or Refined Checkpoints), not by Skill Decile input.

## Rationale

1. **Decile 9 is a distribution-shift target at inference time.** Decile 9
   examples in the BSW corpus come from a self-selecting population of
   strong players in self-selecting contexts. Feeding Decile 9 forces the
   model to predict "what a top BSW player would do in this situation" —
   but the situation at inference is one a *median user* generated by
   their own play, which is out-of-distribution for a Decile-9-conditioned
   policy. Neutral conditioning is in-distribution by construction (it
   was trained on a heterogeneous bucket).
2. **The Neutral bucket gets explicit training signal.** Because the
   Min-games Filter exists, roughly the long tail of BSW handles end up
   in Neutral. This is not a trivial fraction — it is a real subset of
   the corpus with its own decision distribution. The Neutral Embedding
   row is trained, not random.
3. **Decoupling Skill Conditioning from Difficulty keeps two knobs
   orthogonal.** Difficulty selects the *quality of the underlying
   Checkpoint* (small BC vs full BC vs Refined). Skill Conditioning
   selects the *target policy within a Checkpoint*. Conflating them
   would mean a tuning change on one cascades through the other.
4. **It makes phase-2 search principled.** A future search policy that
   uses a Belief-Model-augmented rollout will want to condition each
   simulated opponent on a *plausible* skill, not a maximal one. Neutral
   at inference is the right default; switching to an Decile-dependent
   scheme will be an explicit phase-2 ADR.

## Consequences

- **Difficulty does not change Skill Conditioning.** Difficulty is purely
  a Checkpoint swap. If a future product requirement says "Master should
  feel like playing a Decile-9 player", that's a new ADR.
- **The Neutral Embedding row matters disproportionately.** It is the
  *only* row used at inference for Phase 1. Its training distribution
  must include enough decisions that the embedding is meaningful — the
  Min-games threshold should not be set so high that Neutral becomes a
  near-empty bucket. Worth periodic eval audit: held-out move-prediction
  accuracy conditioned on Neutral should be measured separately.
- **A request-time `skill_decile` parameter is intentionally not exposed.**
  Adding it would invite callers to feed Decile 9 by default, which is
  exactly the failure mode this ADR rejects.

## Rejected alternatives

- **Decile 9 at inference.** Distribution-shift risk (see rationale 1).
  Apparent "use the best policy" framing is misleading because the model
  was conditioned, not weighted.
- **Difficulty-dependent decile.** Couples two orthogonal knobs;
  reintroduces the Decile-9-at-inference problem at the Master tier.
  Revisit only if Neutral conditioning measurably underperforms in
  held-out move prediction.
